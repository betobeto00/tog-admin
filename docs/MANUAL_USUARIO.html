1. Introducción

TOG Admin es un sistema de punto de venta y gestión modular. Se adapta a cualquier negocio y activa los módulos que necesitas según tu licencia.

🛒 Vender

POS rápido con lector de barras, búsqueda, múltiples métodos de pago y terminal de tarjeta.

📦 Inventario

Productos, categorías, unidades, stock mínimo, ajustes con justificación e historial.

💰 Caja

Apertura, cierre, movimientos, reporte X parcial y backup automático.

📊 Reportes

Gráficos por período, top productos, métodos de pago, exportar CSV.

🧾 Cotizaciones

Presupuestos con estados, conversión a venta e impresión.

💳 Créditos

Venta a crédito (fiado) con control de saldos y abonos parciales.

Módulos adicionales (según licencia)

🚚 Distribuidor

Gestión de clientes, pedidos, listas de precio y ruta de entrega.

🍽️ Restaurant

Salón de mesas, comandas, pantalla de cocina y cobro por mesa.

👥 RRHH

Empleados, asistencia, nómina por período con conceptos y deducciones.

📊 Contabilidad

Libros de ventas, compras, inventario y libro diario. Exportar a CSV.

Requisitos Windows 10/11 (64 bits), 4 GB de RAM mínimo, puerto USB (para lector y/o terminal VP800).

2. Primer Inicio

  1. Abre TOG Admin desde el menú Inicio de Windows.
  2. Copia tu ID de máquina (código tipo UUID) y envíaselo al proveedor.
  3. El proveedor te enviará un archivo license.key.
  4. Haz clic en Importar Licencia y selecciona el archivo.
  5. Inicia sesión con admin / admin123. El sistema te obligará a cambiar la contraseña.
Sin licencia válida La aplicación no te dejará iniciar sesión. Conserva tu archivo license.key en un lugar seguro.

3. Iniciar Sesión

Ingresa tu usuario y contraseña. Puedes cambiar el idioma (ES/EN) desde la esquina superior derecha.

Si olvidas tu contraseña Contacta al administrador. Puede restablecerla desde Configuración → Usuarios.
Cuenta bloqueada Tras 5 intentos fallidos, el sistema bloquea el usuario por 15 minutos.

La sesión se cierra automáticamente tras 30 minutos de inactividad.

4. Panel Principal

Al iniciar sesión verás un resumen rápido del día:

  • Ventas de hoy — total vendido y cantidad de tickets.
  • Comparativa — porcentaje vs. el día anterior.
  • Últimas ventas — tabla con las 10 más recientes.
  • Alertas de stock bajo — productos que necesitan reposición.

5. Punto de Venta (POS)

Requisito Debes tener una caja abierta antes de poder vender.

Agregar productos

  • Búsqueda: escribe el nombre en la barra (o presiona F2).
  • Lector de barras: activa el botón Escáner y escanea el código.
  • Venta rápida: para servicios sin producto (describe y pon el monto).

Atajos

AcciónAtajo
Enfocar búsquedaF2
Abrir cobroF5

Cobrar

  1. Pulsa Cobrar (o F5).
  2. Selecciona método de pago (Efectivo, Tarjeta, etc.).
  3. Si es efectivo, ingresa el monto recibido — el sistema calcula el cambio.
  4. Confirma. El ticket se imprime o se cierra sin imprimir.

Carrito

Para cada item puedes: cambiar cantidad, aplicar descuento %, editar precio unitario o eliminar.

6. Caja

Abrir caja

Ve a Caja, pulsa Abrir Caja e ingresa el fondo inicial (sugerido desde Configuración).

Reporte X

Reporte parcial sin cerrar caja. Muestra ventas por método y movimientos.

Movimientos

Registra entradas o salidas de efectivo que no son ventas (gastos menores, ajustes, pagos de deudas).

Cerrar caja

  1. Pulsa Cerrar Caja.
  2. El sistema muestra el esperado calculado.
  3. Cuenta el efectivo físico e ingresa el total real.
  4. El sistema calcula la diferencia (sobrante o faltante).
  5. Agrega notas si lo necesitas y confirma.

7. Inventario

Gestiona productos, categorías, subcategorías y unidades de medida.

Crear producto

Pulsa Nuevo Producto. Campos obligatorios: nombre. Campos opcionales: descripción, código de barras, SKU, categoría, subcategoría, marca, imagen (PNG/JPG/WebP, máx 1 MB), unidad de medida, precio de compra/venta, stock inicial y mínimo.

Producto vs Servicio

Producto: controla stock (compras, ventas y ajustes lo modifican). Servicio: se vende sin control de stock (mano de obra, instalaciones, fletes).

Ajuste manual

Para corregir stock (inventario físico, productos dañados): pulsa el ícono de ajuste, ingresa el nuevo stock y escribe la justificación (obligatoria).

Importar / Exportar CSV

Exporta la lista actual, edítala en Excel e importa el archivo modificado para carga masiva.

8. Compras

Registra el ingreso de mercancía para mantener el stock actualizado.

  1. Ve a Compras → Nueva Compra.
  2. Selecciona proveedor (opcional) y método de pago.
  3. Busca productos por nombre o escanea el código.
  4. Indica cantidad y costo unitario para cada producto.
  5. Pulsa Registrar Compra. El stock se incrementa automáticamente.

9. Ventas

Consulta todas las ventas realizadas con filtros por fecha, ticket o rápidos (Hoy, 7 días, 30 días).

Pulsa sobre una venta para ver detalle: productos, descuentos, impuesto, total, método de pago, cambio y datos del cajero.

Anular venta Solo admin. La venta queda marcada como "anulada" y el stock se devuelve automáticamente.

10. Créditos / Fiado

Vende a crédito: entregas el producto y cobras después. TOG Admin registra la deuda y te permite cobrar por partes.

Vender a crédito en el POS

  1. Agrega productos y pulsa Cobrar.
  2. Elige método Fiado.
  3. Indica el deudor (nombre libre o cliente registrado si tienes módulo Distribuidor).
  4. Opcional: abono inicial.
  5. Confirma. El ticket muestra el saldo pendiente.

Cobrar deudas

Desde Créditos del menú lateral, pulsa el ícono de abono (+), ingresa el monto y confirma. Al llegar a cero, el crédito pasa a Pagado.

11. Cotizaciones

Crea presupuestos para clientes antes de formalizar la venta.

  • Estados: Pendiente → Aprobada / Rechazada / Convertida.
  • Acciones: Aprobar, Rechazar, Convertir a Venta, Editar, Eliminar, Imprimir.

12. Proveedores

Gestiona tu cartera de proveedores (nombre, EIN/RIF, teléfono, email, dirección). Para "eliminar", desactiva al proveedor — sus compras pasadas se conservan.

13. Reportes

Visualiza el rendimiento del negocio con gráficos (ventas por día, top 10 productos, métodos de pago, ventas por categoría). Exporta a CSV o imprime como PDF.

14. Configuración

Solo accesible para administradores. 5 pestañas:

  • Negocio: nombre, EIN/RIF, dirección, teléfono, logo, tasa de impuesto, moneda, impresora, fondo de caja.
  • Usuarios: crear, editar, asignar permisos (ver sección 17).
  • Terminal: configurar VP800 (ver sección 15).
  • Sistema: backups, restaurar, información de licencia.
  • Métodos de Pago: agregar, activar/desactivar métodos (ver sección 16).

15. Terminal VP800

Cobra con tarjeta de crédito/débito usando la terminal Valor VP800.

  1. Conecta el VP800 por USB y verifica el puerto COM en Administrador de Dispositivos.
  2. En Configuración → Terminal, ingresa el puerto (ej: COM3) y pulsa Conectar.
  3. En el POS, selecciona Tarjeta (VP800) al cobrar. El terminal procesa el pago.
Si falla Verifica el cable USB, el puerto COM en Configuración, o reinicia la aplicación.

16. Métodos de Pago

Personaliza qué métodos aparecen en el POS. Predeterminados: Efectivo y Tarjeta (VP800).

Agrega métodos personalizados para pagos frecuentes en tu zona (Zelle, transferencia, crypto, etc.). No es necesario eliminar — solo desactiva y deja de aparecer.

18. Respaldos

Ve a Configuración → Sistema para crear o restaurar backups. Se recomienda hacer backup diario antes de cerrar caja. Si está habilitado, el sistema crea un backup automático al cerrar caja.

Restaurar Reemplaza TODOS los datos actuales. El sistema crea un backup de seguridad (.bak) antes de restaurar.

19. Licencia

Ve a Configuración → Sistema para ver el estado de tu licencia: cliente, fecha de expiración, días restantes e ID de máquina.

Para renovar, solicita una nueva licencia al proveedor e importa el archivo license.key.

Cada licencia está asociada a una máquina Si cambias de PC, necesitarás una licencia nueva.

20. Actualizaciones

TOG Admin incluye auto-actualización. Al iniciar sesión verifica si hay nueva versión. Acepta la descarga, espera el progreso y la app se reinicia con la nueva versión. Tus datos se preservan.

21. Módulo Distribuidor

Gestiona clientes, pedidos y rutas de entrega para distribución.

Clientes

Registra clientes con nombre, teléfono, dirección, límite de crédito y saldo. Los clientes aparecen al vender a crédito y en pedidos.

Pedidos

  1. Ve a Distribuidor → Pedidos.
  2. Crea un pedido seleccionando cliente y agregando productos.
  3. El pedido se marca como Pendiente → En Camino → Entregado.
  4. Al entregar, el stock se descuenta y la venta se registra.

Listas de precio

Crea listas de precio personalizadas por cliente o zona. Al crear un pedido, selecciona la lista aplicable.

22. Módulo Restaurant

Gestiona el salón de mesas, comandas y cobro.

Salón de mesas

Crea mesas con nombre/capacidad. Cada mesa muestra su estado: Libre, Ocupada, Esperando Cobro.

Comandas

  1. Selecciona una mesa libre y pulsa Abrir Comanda.
  2. Agrega productos del menú a la comanda.
  3. Los ítems se envían a la pantalla de cocina.
  4. Al terminar, pulsa Cobrar Mesa y procesa el pago como en el POS.

23. Red Local (PC Base + Hijas)

Conecta varias PCs en tu negocio sin necesidad de licencia en cada una. La PC Base (con licencia) sirve los datos a las PCs Hijas a través de la red local.

Requisito Tu licencia debe incluir max_pcs ≥ 2. Consulta al proveedor para habilitar la red local.

PC Base (con licencia)

  1. Ve a Configuración → Sistema → Red Local.
  2. Haz clic en Generar código de enlace. Aparecerá un código de 6 caracteres (válido 5 min, un solo uso).
  3. Comparte el código y la IP local de la PC con la PC Hija.

La PC Base muestra las PCs ya enlazadas, su IP y la última vez que se conectaron.

PC Hija (sin licencia)

  1. Al iniciar TOG Admin sin licencia, pulsa "Conectar a una PC Base".
  2. Ingresa la IP de la PC Base, el código de enlace y un nombre para esta PC.
  3. La app se conecta, descarga la configuración y queda lista para usar.

La PC Hija no necesita licencia propia: los datos y la licencia los sirve la PC Base.

Desvincular una PC

Desde Configuración → Sistema → Red Local en la PC Hija, pulsa Desvincular esta PC. La PC pierde acceso a los datos de la Base.

Seguridad La conexión se realiza por HTTP/HTTPS con certificado autofirmado. La sesión se valida por IP y código de enlace. Un usuario no puede tener sesión activa en dos PCs al mismo tiempo.

24. Recursos Humanos

Gestiona empleados, asistencia y nómina.

Empleados

Registra empleados con nombre, salario mensual, cargo, nivel académico, años de servicio y contacto.

Asistencia

Registra entrada y salida diaria de cada empleado.

Nómina

  1. Ve a RRHH → Nómina.
  2. Crea un período (fecha inicio/fin).
  3. Agrega conceptos (salario base, bonificaciones, deducciones).
  4. El sistema calcula el total a pagar por empleado.
  5. Marca la nómina como Pagada cuando se procese.

25. Contabilidad

Consulta libros contables generados automáticamente a partir de las operaciones del sistema.

  • Libro de Ventas: cada venta registrada con impuesto desglosado.
  • Libro de Compras: cada compra registrada con costo.
  • Libro de Inventario: valorización de stock actual.
  • Libro Diario: todas las transacciones contables en orden cronológico.

Exporta cualquier libro a CSV para tu contador.

25. Preguntas Frecuentes

¿Funciona sin internet?

Sí. TOG Admin es 100% offline. Solo necesitas internet para actualizaciones.

¿Puedo usar en varias PCs?

No con la misma licencia. Cada PC necesita su propia licencia.

¿Qué pasa si se va la luz?

Los datos se guardan continuamente. Al volver, la app recupera su estado.

¿Cómo cambio el idioma?

Desde la pantalla de login o dentro de la app (menú de usuario).

¿Genera facturas fiscales?

No. Genera tickets de venta como comprobantes internos.

¿Puedo exportar a Excel?

Sí. Usa los botones Exportar CSV en Inventario, Reportes y Ventas.

26. Soporte

Dentro de TOG Admin hay un Centro de Ayuda (ícono ❓) con guía de cada función y atajos de teclado.

Para reiniciar el tutorial de onboarding: Configuración → Sistema → Reiniciar Tutorial.

Si encuentras un error, el sistema genera archivos .txt con el detalle técnico. Envíalos al soporte junto con una descripción del problema.
