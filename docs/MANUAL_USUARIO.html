1. Introducción

Bienvenido a TOG Admin, tu sistema de punto de venta y gestión. Es un ecosistema modular que se adapta a cualquier negocio — desde una tienda de mostrador hasta un distribuidor — y activa los módulos que necesitas según tu licencia. Este manual te guiará paso a paso por todas las funciones disponibles.

¿Qué puedes hacer con TOG Admin?

🛒 Vender rápido

Procesa ventas en segundos con lector de códigos de barras, búsqueda rápida y múltiples métodos de pago.

📦 Controlar inventario

Gestiona productos, categorías, unidades de medida y alertas de stock bajo.

💰 Manejar caja

Apertura, cierre, movimientos de efectivo y reporte X parcial sin cerrar caja.

📊 Analizar ventas

Reportes por período, productos más vendidos, ventas por categoría y métodos de pago.

🧾 Cotizar clientes

Crea presupuestos con validez, aprobación y conversión a venta.

🔌 Terminal VP800

Cobra con tarjeta de crédito/débito directamente en el POS.

A quién está dirigido

  • Dueños y administradores de cualquier negocio comercial (retail, servicios, distribución).
  • Cajeros y vendedores que procesan ventas a diario.
  • Negocios con una sola caja registradora en una PC.
Requisitos del sistema Windows 10/11 (64 bits), 4 GB de RAM mínimo, puerto USB disponible (para lector y/o terminal VP800).

2. Primer Inicio

Si acabas de instalar TOG Admin por primera vez, sigue estos pasos para configurar tu negocio.

Paso 1: Iniciar la aplicación

  1. Busca "TOG Admin" en el menú Inicio de Windows y ábrelo.
  2. Aparecerá la pantalla de bienvenida con un campo para tu ID de máquina.

Paso 2: Activar la licencia

  1. Copia tu ID de máquina (es un código largo tipo UUID).
  2. Envíaselo al proveedor del software.
  3. El proveedor te enviará un archivo license.key.
  4. Haz clic en "Importar Licencia" y selecciona el archivo.
  5. La aplicación se activará y mostrará la pantalla de login.
Importante Sin licencia válida, la aplicación no te dejará iniciar sesión. Conserva tu archivo license.key en un lugar seguro.

Paso 3: Iniciar sesión por primera vez

El sistema crea automáticamente un usuario administrador:

  • Usuario: admin
  • Contraseña temporal: admin123
  1. En la pantalla de login, ingresa admin y admin123.
  2. El sistema te pedirá cambiar la contraseña inmediatamente. Elige una contraseña segura (mínimo 6 caracteres).
  3. Una vez cambiado, verás el Panel Principal.
Consejo de seguridad No uses contraseñas obvias como "123456" o tu nombre. Combina letras, números y símbolos.

Paso 4: Configurar tu negocio

Antes de empezar a vender, ve a Configuración y completa:

  1. Datos del Negocio: nombre, dirección, teléfono, EIN, logo.
  2. Impuestos: tasa de impuesto (por defecto 0%).
  3. Operación: nombre de impresora térmica, fondo inicial de caja.
  4. Usuarios: crea cuentas para tus cajeros.

Más detalles en la sección 14. Configuración.

3. Iniciar Sesión

Cada vez que abras TOG Admin verás la pantalla de login.

Acceder

  1. Ingresa tu usuario (no tu email, sino tu nombre de usuario).
  2. Ingresa tu contraseña.
  3. Pulsa Iniciar Sesión o presiona Enter.

Seleccionar idioma

En la esquina superior derecha de la pantalla de login puedes cambiar entre Español e Inglés. La preferencia se guarda automáticamente.

Cambiar contraseña

Si el sistema te obliga a cambiar la contraseña (primer login o un administrador lo decidió), completa el formulario:

  • Tu contraseña actual.
  • La nueva contraseña (mínimo 6 caracteres).
  • Repite la nueva contraseña.

Problemas al iniciar sesión

Si olvidas tu contraseña Contacta al administrador del sistema. Él puede restablecerla desde Configuración → Usuarios.
Cuenta bloqueada Tras 5 intentos fallidos, el sistema bloquea el usuario por 15 minutos. Espera y vuelve a intentar.

Sesión por inactividad

Por seguridad, la sesión se cierra automáticamente tras 30 minutos de inactividad. Tu trabajo no guardado se conservará al volver a iniciar sesión.

5. Punto de Venta (POS)

El POS es el corazón del sistema. Aquí procesas cada venta.

Requisito Debes tener una caja abierta antes de poder vender. Si no la hay, el POS te mostrará una alerta con un botón para ir a Caja.

Atajos de teclado

AcciónAtajo
Enfocar búsqueda de productosF2
Abrir modal de cobroF5
Buscar producto al escribir(automático)

Agregar productos al carrito

Tienes tres formas de agregar productos:

Método 1: Búsqueda por nombre

  1. Haz clic en la barra de búsqueda (o presiona F2).
  2. Escribe el nombre del producto. Verás resultados en tiempo real (máximo 20).
  3. Haz clic en el producto para agregarlo al carrito.

Método 2: Lector de código de barras

  1. Activa el botón Escáner (esquina superior izquierda del POS).
  2. Escanea el código del producto. Se agrega automáticamente.
  3. Si no existe, verás una advertencia y el código quedará en el buscador.
Tip El escáner distingue entre tipeo manual y escaneo (umbral de 50ms entre teclas). Puedes tener el escáner activo y tipear al mismo tiempo sin conflictos.

Método 3: Venta rápida (servicio)

Para ventas sin producto (ej: copias, envíos):

  1. Pulsa + Venta Rápida (Servicio).
  2. Escribe la descripción (ej: "10 copias B/N").
  3. Ingresa el monto.
  4. Pulsa Agregar al carrito.

El carrito

A la derecha verás el carrito con todos los productos agregados. Para cada item puedes:

  • Cambiar cantidad con los botones + y −.
  • Aplicar descuento por item (porcentaje 0-100%).
  • Editar precio unitario (útil para ajustes manuales).
  • Eliminar el item con el ícono de papelera.

Vacía todo el carrito con Vaciar carrito.

Totales

El panel inferior del carrito muestra el desglose en tiempo real:

ConceptoDescripción
Subtotal brutoSuma de precio × cantidad sin descuentos.
Descuento por itemSuma de descuentos aplicados por item.
Descuento global (%)Aplica un porcentaje al subtotal neto.
Subtotal netoTras aplicar todos los descuentos.
ImpuestoTasa configurada en Configuración (0% por defecto).
TotalMonto final a cobrar.

Cobrar la venta

  1. Pulsa el botón verde Cobrar (o F5).
  2. Aparecerá el modal con el total y los métodos de pago disponibles.
  3. Selecciona el método (Efectivo, Tarjeta, etc.).
  4. Si es efectivo, ingresa el monto recibido — el sistema calcula el cambio.
  5. Si es tarjeta, sigue las instrucciones del terminal (ver sección 14).
  6. Pulsa Confirmar Pago.

Ticket y cierre

Tras confirmar el pago verás el ticket digital. Puedes:

  • Imprimirlo en la impresora térmica configurada.
  • Cerrarlo sin imprimir.

Anular una venta

Si necesitas anular una venta ya procesada (no desde el POS, sino desde el historial):

  1. Ve a Ventas.
  2. Encuentra la venta.
  3. Pulsa el ícono de anular.
  4. Ingresa el motivo (obligatorio).
  5. El stock se devuelve automáticamente.
Solo admin puede anular ventas (configurable en permisos).

6. Gestión de Caja

La caja registradora controla todo el flujo de efectivo.

Abrir caja

  1. Ve a Caja.
  2. Pulsa Abrir Caja.
  3. Ingresa el monto de apertura (el efectivo con el que inicias el día).
  4. Pulsa Abrir Caja de nuevo.
El monto sugerido se carga automáticamente desde Configuración → Operación (por defecto $100, editable).

Estado de caja abierta

Una vez abierta verás tarjetas de resumen:

  • Fondo inicial: efectivo con el que arrancaste.
  • Ventas: suma de ventas del día (en efectivo).
  • Entradas: dinero extra que entró (ver movimientos).
  • Salidas: retiros o gastos.
  • Esperado: cálculo automático (fondo + ventas + entradas - salidas).

Reporte X (parcial)

Un reporte parcial sin cerrar caja. Útil para supervisores o para imprimir a media tarde.

  1. Con la caja abierta, pulsa Reporte X.
  2. Verás el resumen con ventas por método de pago y movimientos.
  3. Pulsa Imprimir si lo necesitas.

Movimientos de caja

Registra entradas o salidas de efectivo que no son ventas:

  • Entradas: pagos de deudas, ajustes, dinero extra.
  • Salidas: gastos menores, retiros.
  1. Pulsa Movimiento.
  2. Selecciona tipo (entrada/salida).
  3. Ingresa monto y descripción.
  4. Confirma.

Cerrar caja

  1. Al final del día, pulsa Cerrar Caja.
  2. El sistema muestra el esperado calculado.
  3. Cuenta el efectivo físico e ingresa el total real.
  4. El sistema calcula la diferencia (sobrante o faltante).
  5. Opcional: agrega notas (ej: "Faltante por vuelto mal dado").
  6. Pulsa Cerrar Caja.
Backup automático Al cerrar caja, el sistema crea un backup automático de la base de datos (si está habilitado en Configuración).

Historial de cajas

Consulta cajas cerradas anteriormente con sus totales y diferencias.

7. Inventario y Productos

Gestiona todos los productos que vendes.

Lista de productos

Ve a Inventario para ver la lista. Cada producto muestra:

  • Nombre, descripción, código de barras, SKU.
  • Categoría, unidad de medida.
  • Precio de compra, precio de venta, stock, stock mínimo.

Crear un producto

  1. Pulsa Nuevo Producto.
  2. Completa los campos:
    • Nombre* (obligatorio).
    • Descripción (opcional).
    • Código de barras (para lector USB).
    • SKU (código interno).
    • Tipo de producto: Producto o Servicio (los servicios se venden sin control de stock).
    • Categoría (creala primero si no existe) y Subcategoría (opcional, de esa categoría).
    • Marca (opcional).
    • Imagen (opcional, PNG/JPG/WebP hasta 1 MB).
    • Unidad de medida (unidad, paquete, caja, etc.).
    • Precio de compra y Precio de venta.
    • Stock inicial y Stock mínimo (solo aplican a productos).
  3. Pulsa Guardar.

Editar producto

Pulsa el ícono de lápiz sobre un producto. Modifica lo que necesites y guarda.

Eliminar producto

TOG Admin usa borrado lógico: el producto se marca como inactivo pero permanece en la base de datos para preservar el historial de ventas.

Categorías

Crea categorías para organizar productos (ej: "Cuadernos", "Bolígrafos", "Servicios"). Ve a Inventario → Nueva Categoría.

Subcategorías

Organiza los productos dentro de cada categoría con Subcategorías (ej: Papelería → Cuadernos, Lápices). Ve a Inventario → Subcategorías para crearlas, y asígnalas en el formulario del producto.

Producto vs Servicio

Al crear un producto eliges su Tipo: Producto (controla stock: compras, ventas y ajustes lo descuentan/suman) o Servicio (mano de obra, instalaciones, fletes — se vende sin control de stock). Puedes vender servicios desde el POS usando los productos tipo Servicio o el botón de Venta Rápida.

Marca e imagen

Opcionalmente agrega una Marca (visible en la lista y buscable) y una Imagen del producto (PNG/JPG/WebP, máximo 1 MB) que aparece como miniatura en Inventario.

Unidades de medida

El sistema incluye unidades predefinidas: Unidad, Paquete, Caja, Resma, Rollo, Litro, Galón, Hoja, Metro, Par, Servicio. Puedes crear unidades personalizadas. La unidad es solo informativa: el control de stock depende del tipo Producto/Servicio.

Ajuste manual de stock

Para corregir el stock (ej: inventario físico, productos dañados):

  1. Pulsa el ícono de ajuste sobre el producto.
  2. Ingresa el nuevo stock.
  3. Escribe la justificación (obligatoria, queda en el historial).
  4. Confirma.

Historial de ajustes

Consulta todos los ajustes con usuario, fecha, stock anterior y nuevo, y justificación. Útil para auditoría.

Importar / Exportar CSV

Para carga masiva de productos:

  1. Pulsa Exportar CSV para descargar la lista actual.
  2. Edita el CSV con tu editor favorito.
  3. Pulsa Importar CSV y selecciona el archivo.

Lector de código de barras en Inventario

Al crear o editar un producto, puedes activar el escáner para llenar el código automáticamente. Funciona igual que en el POS.

9. Ventas e Historial

Consulta todas las ventas realizadas.

Lista de ventas

Muestra cada venta con número de ticket, fecha, cajero, método de pago, total y estado.

Filtros

  • Por rango de fechas (inicio/fin).
  • Por número de ticket (búsqueda).
  • Filtros rápidos: Hoy, últimos 7 días, últimos 30 días.

Detalle de venta

Pulsa sobre una venta para ver:

  • Productos vendidos con cantidad, precio, descuento.
  • Subtotal, descuentos, impuesto, total.
  • Método de pago, monto pagado, cambio.
  • Notas (si las hay).
  • Datos del cajero.

Re-imprimir ticket

Para reimprimir un ticket de venta anterior, pulsa el ícono de impresora en la fila.

Anular venta

Solo para administradores:

  1. Selecciona la venta (no debe estar ya anulada).
  2. Pulsa el ícono de anular.
  3. Ingresa el motivo.
  4. Confirma.

La venta queda marcada como "anulada" y el stock se devuelve automáticamente.

10. Venta a Crédito / Fiado

Puedes vender a crédito (fiado): entregas el producto o servicio y cobras ahora una parte (o nada) y el resto después. TOG Admin registra la deuda y te permite cobrarla por partes desde la sección Créditos.

Vender a crédito en el POS

  1. Agrega los productos al carrito y pulsa Cobrar.
  2. Elige el método de pago Fiado.
  3. Indica el deudor: selecciona un cliente registrado (si tu licencia incluye el módulo Distribuidor, se valida su límite de crédito) o escribe un nombre libre con su teléfono.
  4. Opcional: escribe un abono inicial (cuánto paga ahora; puede ser 0).
  5. Confirma la venta. El ticket muestra el saldo pendiente.

Cobrar deudas (abonos)

Abre la sección Créditos del menú lateral. Verás las deudas pendientes (con su saldo), pagadas y anuladas, y podrás buscarlas y filtrarlas por estado.

  1. Pulsa el ícono de abono (+) sobre la deuda, o ábrela con el ícono de ojo para ver el detalle de la venta y el historial de pagos.
  2. Escribe el monto del pago (no puede superar el saldo) y una nota opcional.
  3. Confirma: el saldo baja y, al llegar a cero, el crédito pasa a estado Pagado.

Si hay una caja abierta, los abonos entran como movimiento de caja (entrada). Al anular una venta a crédito que aún no tiene cobros, el crédito se anula junto con la venta; si ya tiene abonos, la anulación queda bloqueada.

¿Necesito el módulo Distribuidor para vender fiado? No. La venta a crédito es del núcleo (Comercializador). El módulo Distribuidor solo agrega la posibilidad de vincular la deuda a un cliente registrado y validar su límite de crédito.

11. Cotizaciones

Crea presupuestos para clientes antes de formalizar la venta.

Crear cotización

  1. Ve a Cotizaciones.
  2. Pulsa Nueva Cotización.
  3. Ingresa los datos del cliente (nombre, email, teléfono, dirección).
  4. Agrega productos (por nombre o personalizados).
  5. Opcional: fecha de vencimiento.
  6. Opcional: notas.
  7. Pulsa Guardar.

Estados

  • Pendiente: recién creada, aún no decidida.
  • Aprobada: el cliente aceptó.
  • Rechazada: el cliente no aceptó.
  • Convertida: se convirtió en una venta.

Acciones sobre cotizaciones pendientes

  • Aprobar, Rechazar o Convertir a Venta.
  • Editar (solo en estado pendiente).
  • Eliminar.
  • Imprimir el presupuesto en formato profesional.

15. Terminal de Tarjeta VP800

Conecta la terminal de pago Valor VP800 para cobrar con tarjeta de crédito/débito directamente desde el POS.

Requisitos

  • Terminal Valor VP800 con cable USB.
  • Puerto USB disponible en la PC.
  • Drivers del puerto serial virtual (la mayoría de Windows los instala automáticamente).

Conectar el terminal

  1. Conecta el VP800 a la PC por USB.
  2. Abre Administrador de Dispositivos de Windows → Puertos (COM y LPT).
  3. Busca el puerto asignado (ej: COM3, COM4).
  4. En TOG Admin ve a Configuración → Terminal.
  5. Ingresa el puerto (ej: COM3).
  6. Baud Rate: 9600 por defecto.
  7. Pulsa Conectar Terminal.
  8. El indicador pasará a verde "Conectado".

Procesar un pago con tarjeta

  1. En el POS, agrega productos al carrito.
  2. Pulsa Cobrar.
  3. Selecciona Tarjeta (VP800).
  4. Pulsa Confirmar Pago.
  5. El sistema enviará el monto al terminal.
  6. El terminal mostrará "Inserte/Tarjee la tarjeta".
  7. El cliente pasa, inserta o tarjea la tarjeta.
  8. Si aprobada, la venta se registra con el código de autorización.

Si algo falla

Terminal no responde
  1. Verifica que el cable USB esté bien conectado.
  2. Comprueba el puerto COM en Configuración → Terminal.
  3. Desconecta y vuelve a conectar.
  4. Si persiste, reinicia la aplicación.

Información registrada

Cada venta con tarjeta guarda:

  • Número de referencia bancaria.
  • Código de autorización.
  • Tipo de tarjeta (crédito/débito).
  • Últimos 4 dígitos de la tarjeta.

16. Métodos de Pago

Personaliza qué métodos de pago aparecen en el POS.

Métodos predeterminados

Al instalar, el sistema incluye dos métodos preconfigurados:

  • Efectivo: cobro tradicional.
  • Tarjeta (VP800): marcado como "Requiere Terminal".

Agregar un método nuevo

  1. Ve a Configuración → Métodos de Pago.
  2. Pulsa Nuevo Método.
  3. Ingresa el nombre (ej: "Zelle", "Crypto", "Cheque").
  4. Define la clave interna (sin espacios, ej: "zelle").
  5. Elige un icono.
  6. Marca Requiere Terminal VP800 si quieres que procese con tarjeta.
  7. Pulsa Crear.

Activar / Desactivar

No es necesario eliminar un método. Solo desactívalo y dejará de aparecer en el POS. El historial de ventas pasadas se conserva.

Editar

Pulsa el ícono de lápiz sobre un método. Puedes cambiar nombre, icono, orden o si requiere terminal.

Buenas prácticas Usa métodos personalizados para pagos frecuentes en tu zona (Zelle, Yappy, transferencia bancaria local, etc.). Así el reporte de métodos de pago será exacto.

17. Usuarios y Permisos

Solo accesible para administradores.

Lista de usuarios

Ve a Configuración → Usuarios para ver la lista. Cada usuario tiene:

  • Nombre de usuario (único, no editable).
  • Nombre completo.
  • Rol: Administrador o Cajero.
  • Estado: Activo o Inactivo.

Crear usuario

  1. Pulsa Nuevo Usuario.

18. Respaldos y Restauración

Protege tu información con backups regulares.

Crear un backup

  1. Ve a Configuración → Sistema.
  2. Pulsa Crear Backup.
  3. Elige dónde guardar el archivo .db.
Recomendación Haz backup a diario, idealmente antes de cerrar caja. Guarda los backups en un lugar seguro fuera de la PC (USB, nube).

Backup automático al cerrar caja

Si está habilitado, el sistema crea un backup automáticamente cada vez que se cierra caja. Verifica esta opción en la sección correspondiente.

Restaurar un backup

Atención Restaurar reemplaza TODOS los datos actuales. El sistema crea un backup de seguridad automático (.bak) antes de restaurar.
  1. Ve a Configuración → Sistema.
  2. Pulsa Restaurar Backup.
  3. Selecciona el archivo .db.
  4. Confirma la operación.
  5. La aplicación se reiniciará con los datos restaurados.

19. Licencia

La licencia controla el uso legítimo del software.

Ver tu licencia

Ve a Configuración → Sistema. Verás:

  • Estado: Válida o No válida.
  • Cliente: nombre asociado.
  • Fecha de expiración.
  • Días restantes.
  • ID de máquina (necesario para renovar).

Importar licencia

Si recibes un nuevo archivo license.key:

  1. Ve a Configuración → Sistema.
  2. Pulsa Importar Nueva Licencia.
  3. Selecciona el archivo.
  4. Espera la confirmación.
Importante Cada licencia está asociada a una máquina específica (por su ID). Si cambias de PC, necesitarás una licencia nueva.

21. Preguntas Frecuentes

¿Puedo usar TOG Admin en varias PCs?

No con la misma licencia. Cada licencia está asociada a una máquina. Para múltiples PCs necesitas múltiples licencias.

¿Qué pasa si se va la luz?

TOG Admin guarda los datos continuamente. Al volver la luz, la aplicación recupera su estado. Si había una venta a medio procesar, se descartará sin afectar el stock.

¿Cómo cambio el idioma?

Desde la pantalla de login (esquina superior) o dentro de la app si tienes sesión iniciada (menú de usuario).

¿Puedo usar mi propio logo en tickets?

Sí. Configuración → Negocio → Logo. Usa PNG con transparencia, idealmente 400×200 px o 600×300 px.

¿Puedo tener varios cajeros al mismo tiempo?

No en la misma PC. Para múltiples cajas simultáneas necesitas múltiples PCs (cada una con su licencia).

¿Cómo hago factura?

TOG Admin no genera facturas fiscales (en Latinoamérica eso requiere integración con sistemas de facturación electrónica del país). Genera tickets de venta que puedes usar como comprobantes internos.

¿Puedo exportar a Excel?

Sí. En la mayoría de las tablas (Inventario, Reportes, Ventas) hay botones Exportar CSV que generan archivos compatibles con Excel.

¿La aplicación funciona sin internet?

Sí. TOG Admin es 100% offline. Toda la información se guarda en una base de datos local en tu PC. Solo necesitas internet para verificar actualizaciones.

¿Cómo cambio la tasa de impuesto?

Configuración → Negocio → Tasa de Impuesto. Cambia el valor y guarda.
